# KoFLEURS-R demo page

Demo page for "KoFLEURS-R: Improving Text and Audio Consistency in the Korean FLEURS-R Corpus" (ICEIC 2027).
Static HTML based on the [Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template) (CC BY-SA 4.0); no build step.

## Files

| Path | Content |
|---|---|
| `index.html` | the page: abstract, Fig. 1, method overview, three examples, BibTeX |
| `static/js/config.js` | settings: `showAuthors` (blind review), `reviewMode`, BibTeX venue |
| `static/js/authors.js` | author names, affiliation, paper link (loaded only when `showAuthors` is true) |
| `static/js/site.js` | renders the examples from `static/data/demo_data.json`; spectrogram playhead and zoom |
| `static/css/site.css` | styles (Bulma from the template + page styles, light and dark) |
| `static/data/demo_data.json` | texts, slot scores, word times per recording (generated) |
| `static/audio/`, `static/spectrograms/` | 128 kb/s MP3 at the original 24 kHz, log-mel PNGs (magma) |

The examples were chosen from the experiment results:

| Example | Recording | Why |
|---|---|---|
| 1. Omission | `14945311428794587488` (+ `14152602067612134390`, same script, parenthetical read) | one of the 189 human-verified recordings; the largest reduction after refinement |
| 2. Insertion | `14689351762998088074` (+ `10849776261913860801`, same script, gloss skipped) | gloss read again in Hangul; clearest of the 12 such decisions (train split, not human-verified) |
| 3. Substitution | `11800040547070956694` (+ `1807970046287819091`, same script, default reading) | human-verified; "25" read 이십오, as the annotator's spoken form confirms |

`demo_data.json`, the audio and the spectrograms are generated by `demo/scripts/build_demo_assets.py` of the research repository; the examples are set in `EXAMPLES` there.

## Local preview

```bash
python3 -m http.server 8000   # http://localhost:8000 (seeking in audio needs a Range-capable server such as GitHub Pages)
```
